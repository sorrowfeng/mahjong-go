# 麻将消消乐

纯 HTML/CSS/JavaScript 开发的网页麻将消消乐游戏，无需任何框架或构建工具，直接双击 `index.html` 即可游玩。

## 游戏规则

### 牌组
- **136张牌**：万子 36（1-9万×4）、条子 36（1-9条×4）、筒子 36（1-9筒×4）、字牌 28（东南西北中发白×4）
- 开局行列数由视口**自适应**：横屏默认 17×8，竖屏 8×17，极小屏幕自动枚举最优布局并计算牌尺寸

### 消除规则

| 规则 | 说明 |
|------|------|
| 直接消除 | 同行或同列中，两张相同牌之间**无任何牌遮挡**时，点击即可消除 |
| 拖动消除 | 拖动一张牌时，**同方向相邻的牌会一起移动**；松手后若与其他行/列的相同牌满足消除条件，则触发消除，否则复原 |
| 连锁消除 | **拖动**消除后，若移动产生了新的可消除对则持续连锁（只连锁移动新增的配对，已存在的配对需手动点击） |

### 操作方式
- **点击**：直接消除同行/列中无遮挡的相同牌
- **拖动**：点击并拖动，超过阈值后锁定横/纵方向；同方向上与起点相邻的牌会一起移动
- 移动受阻挡时自动停在前一格，无法移出棋盘边界

### 键盘完全可玩（无障碍）
不借助鼠标也能完整游玩：

| 按键 | 作用 |
|------|------|
| `方向键` | 在棋盘上移动高亮光标（自动跳过空格、越界回绕） |
| `回车` | 光标落在可直接消除的牌上 → 点击消除；否则将其**选中为拖拽起点** |
| `方向键`（选中起点后） | 预选拖拽方向 |
| `回车`（预选方向后） | 执行该方向拖拽（复用与鼠标完全相同的消除/连锁逻辑） |
| `Esc` | 取消起点选中 |

绿色光标表示该格可直接配对消除，橙色表示需要拖拽。屏幕底部有操作提示条。
同时提供 **aria-live 无障碍播报**：胜利、死局、超时、步数用尽、重排等关键事件会向读屏软件播报。

## 按钮功能

| 按钮 | 功能 |
|------|------|
| 规则 | 查看带动画演示的游戏规则说明 |
| 提示 | 高亮显示当前可操作的步骤（含按住哪张牌、往哪个方向拖）；确认无可消除步骤后弹窗询问是否**重新随机排列**剩余牌 |
| 撤销 | 还原上一步操作（最多保留 20 步，增量渲染无闪烁） |
| 新游戏 | 重新洗牌，预加载牌图并播放发牌动画后开始新局 |

## 存档与最佳成绩

- 对局进行中自动保存到浏览器 `localStorage`（棋盘快照 + 步数 + 用时），刷新或关闭页面后再次打开会询问"**继续上局**"
- 通关后记录**最佳成绩**（最短用时、最少步数、完成局数），显示在胜利界面
- 教学关卡不入档；通关或开新局会清空存档

## 胜利条件

消除所有 136 张麻将牌即通关，胜利界面显示本局用时、有效操作步数与历史最佳成绩。

## 游戏模式

游戏支持多种模式，可在工具栏「模式」面板切换。模式本质是**参数包**，叠加在相同的核心消除规则之上，消除玩法不变：

| 模式 | 规则叠加 | 说明 |
|------|----------|------|
| 经典模式 | 无附加参数 | 默认模式，不限时、不限步数，自由畅玩 |
| 限时挑战（60s） | 60 秒倒计时 | 倒计时结束按当前分数结算，剩余时间转化为额外分数与星级 |
| 限时挑战（120s） | 120 秒倒计时 | 同上，时限更宽松 |
| 步数挑战（30 步） | 限 30 步清盘 | 剩余步数转化为分数与星级 |
| 步数挑战（50 步） | 限 50 步清盘 | 同上，预算更宽裕 |
| 每日挑战 | 以 `YYYY-MM-DD` 作随机种子 | 全网同题，本地可复现；不分模式的难度，仅换一种计分维度 |

- 模式定义集中在 `js/modes.js`（`MODES` 数据表），各模式通过 `timeBudget` / `moveBudget` / `undoLimit` / `hintLimit` / `seedType` / `scoring` 参数叠加规则。
- 限时/步数模式下，未通关也会弹出结算界面，按当前成绩计分与评星。
- 「继续上局」恢复限时模式时，倒计时从上次剩余时间继续。

## 计分与星级

消除不再只有"通关/未通关"，而是有完整的计分与星级评定：

- **基础分**：每消除一对记 100 分。
- **连锁倍率**：连锁消除第 n 次 ×(1 + 0.5·(n−1))，鼓励一次性拖出多段连锁。
- **连击奖励**：每累计 5 连击额外 +80 分。
- **效率奖励**：一次拖动消除多对，每多一对额外 +40 分。
- **剩余奖励**：步数挑战每剩余 1 步 +10 分；限时挑战每剩余 1 秒 +2 分。
- **星级**：按本局得分相对理想满分分档，一/二/三星对应 60% / 85% / 110% 的达标线（可配置）。
- **分数榜**：每种模式的最佳得分独立记录到 `localStorage`（`mahjong-scores-v1`），显示在胜利/结算界面。

计分纯逻辑集中在 `js/score.js`，不依赖 DOM，便于测试与复用。

## 道具

工具栏新增道具栏，默认库存为 3 洗牌 / 3 撤销 / 5 提示 / 2 锤子（存于 `localStorage` `mahjong-items-v1`）：

| 道具 | 效果 |
|------|------|
| 🔀 洗牌 | 免确认直接重新随机排列剩余牌（等价现有重排） |
| ↩️ 撤销 | 多解锁一次撤销机会 |
| 💡 提示 | 多解锁一次提示机会 |
| 🔨 锤子 | 点击直接消除任意一对牌（无视拖动规则），消除后仍会触发连锁 |

道具库存由 `js/items.js` 管理（不可变账本 + 能力回调注入副作用），使用道具时需处于可操作阶段。

## 关卡挑战

工具栏「关卡」面板提供 **12 个递进关卡**，每个关卡都是独立配置的棋盘（尺寸 / 牌型子集 / 步数 / 提示与撤销限额 / 目标分数 / 星级门槛）：

- **难度曲线**：前几关教学性质（宽棋盘、限额宽松）→ 中期收紧步数/提示 → 后期窄棋盘 + 极紧限额
- **种子化发牌**：每关固定随机种子，同关重开棋盘一致
- **进度解锁**：通关即解锁下一关；每关记录 1-3 星
- **进度存档**：`mahjong-progress-v1` 保存已解锁关数与各关星级

关卡定义集中在 `js/levels.js`（`LEVELS` 数据表），关卡进度/星级/解锁逻辑为纯函数。

## 成就

工具栏「成就」面板展示本地成就系统（`mahjong-achievements-v1`），达成时弹出 toast 提示：

| 成就 | 达成条件 |
|------|----------|
| 🏆 初露锋芒 | 首次通关 |
| ⚔️ 常胜将军 | 累计通关 10 次 |
| 🎯 百发百中 | 累计消除 100 对 |
| 🔨 千锤百炼 | 累计消除 500 对 |
| ⛓️ 连锁大师 | 单局触发 5 段连锁 |
| 🧹 无懈可击 | 无提示、无撤销通关 |
| 📅 风雨无阻 | 完成每日挑战 |
| ⭐ 完美主义者 | 任一关卡三星通关 |
| 👑 登峰造极 | 全部关卡通关 |
| 💨 行云流水 | 30 步以内通关 |

成就判定集中在 `js/achievements.js`（定义数据化 + 纯逻辑判定 + toast 通知）。

## 分享成绩

通关/结算界面的「分享」按钮把成绩（模式/关卡、用时、步数、得分、星级）生成文本分享：**Web Share API 优先，剪贴板兜底**。另外可用「存卡片」把成绩绘制成 **Canvas 成绩卡片 PNG** 下载保存。纯逻辑见 `js/share.js`。

## PWA 离线支持

项目内置 PWA 能力，**部署到 HTTP(S)/localhost 后**可离线游玩、可安装到桌面/主屏：

- `manifest.webmanifest`：应用名、图标、主题色、standalone 展示
- `sw.js` + `js/sw-register.js`：Service Worker 预缓存应用外壳 + 运行时缓存牌图；发现新版本时提示刷新
- 注意：`file://` 直接打开时浏览器不注册 SW（无离线能力，但游戏照常运行）

## 存档与最佳成绩

- 对局进行中自动保存到浏览器 `localStorage`（棋盘快照 + 步数 + 用时），刷新或关闭页面后再次打开会询问"**继续上局**"
- 通关后记录**最佳成绩**（最短用时、最少步数、完成局数），显示在胜利界面
- 教学关卡不入档；通关或开新局会清空存档
- 存档已升级到 v2（`mahjong-save-v2`，含模式/分数/本局连击等字段），自动兼容旧版 v1 存档
